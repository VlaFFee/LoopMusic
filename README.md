# Music Loop — Forge 1.20.1 (47.3.0)

Бесшовные лупы музыки из папки, управляются командами, одинаково звучат у всех игроков.

## Сборка через GitHub
1. Новый репозиторий -> залей СОДЕРЖИМОЕ этой папки (в корне должны лежать `build.gradle` и `.github`).
2. Вкладка **Actions** -> **Build mod** -> внизу **Artifacts** -> `musicloop-jar`.
3. Достань jar и положи в `mods`.

## Музыка
При первом запуске создаётся папка `<папка игры>/music_loops`. Кидай туда `.ogg` (Vorbis) или `.wav`.
Открыть папку из игры: `/musicloopfolder`.
mp3 надо сконвертировать: `ffmpeg -i in.mp3 -c:a libvorbis -q:a 5 out.ogg`.

## Команды (нужны права оператора / читы)
* `/musicloop play <файл> [секунд]` — запустить луп для всех (имена подсказываются по Tab). Если уже играет другой трек — плавный кроссфейд.
* `/musicloop stop [секунд]` — плавно затухнуть (по умолчанию 4 с).
* `/musicloop list` — список треков.

## Синхронизация
Сервер запоминает время старта по своим часам. Клиент постоянно уточняет разницу своих часов с серверными
(пинг-понг, как в NTP, берётся замер с самым маленьким пингом) и от этого считает позицию в треке.
Поэтому все слышат одно и то же место, в том числе зашедшие в мир позже: загрузка мира или лаги главного потока
на точность не влияют. Остаточный дрейф выравнивается микро-изменением скорости (0.3-0.6%, на слух незаметно),
при большом рассинхроне (>0.15 с) трек незаметно перезапускается с нужной позиции.
**У всех игроков в `music_loops` должны лежать одинаковые файлы с одинаковыми именами.**

## Громкость
В Настройки -> Звук внизу списка есть отдельный ползунок **Музыка лупа**. Он не зависит от ползунка «Музыка» (ванильной).
Общая громкость (Master) на луп действует, как на любой звук.

## Приглушение
* Окно свёрнуто: луп плавно становится очень тихим (`minimizedLevel`, по умолчанию 7%), но остаётся слышен; при разворачивании так же плавно возвращается.
* Открыта записка / фото / выбор фото (мод записок): луп плавно приглушается до `duckLevel` (50%) и возвращается после закрытия.

Настройки — `config/musicloop-client.toml`: `loopVolume`, `minimizedLevel`, `duckWhenUnfocused` (приглушать и при alt-tab),
`duckLevel`, `duckFadeSeconds`, `suppressVanillaMusic`.
